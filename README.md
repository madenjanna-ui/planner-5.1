# MaDenFlow 7.2

Обновление недельного планировщика:
- выбор только между одной и двумя колонками;
- отдельная настройка плотности для каждого режима;
- одна колонка: 4, 6 или 12 дел; две колонки: 4–12 дел;
- воскресенье в режиме двух колонок автоматически показывает столько дел, сколько помещается;
- одинаковая высота карточек четверга–субботы, воскресенье ниже;
- уменьшены внутренние отступы карточек, шрифт дел управляется через «Оформление»;
- настройка количества дел удалена из «Оформления» и находится в общих настройках.

Для публикации замените файлы проекта содержимым архива, сохранив структуру каталогов.
